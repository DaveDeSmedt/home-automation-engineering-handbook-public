# Roadmap

## Purpose

This roadmap tracks editorial and educational improvements to the public book. It does not describe a specific home's implementation plan.

## Next editorial release

### v1.1.0 final

- Complete release-candidate privacy, technical and licensing review.
- Resolve any residual redaction findings.
- Check every Mermaid diagram in Obsidian.
- Confirm the bibliography and links against current primary sources.
- Choose a licence and contribution policy, if publication is approved.

## Future chapters

- A fully worked HomeyScript example that is safe to run in a non-production test environment.
- A test worksheet for timing-sensitive presence and audio flows.
- A chapter on change management for shared households.
- A reference appendix for defining manual override policies.
- A vendor-neutral comparison of local, cloud and hybrid integrations.

## Explicitly out of scope

- Any real installation map, network plan, account configuration, security layout or device inventory.
- Product reviews, product certification or electrical design.
- A promise that a flow or integration card exists in every version of Homey or every third-party app.

## Contribution rule

Contributions must improve a reusable pattern, evidence standard, explanation or template. Submit private operational facts only to a separate private repository.
