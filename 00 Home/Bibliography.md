# Bibliography

This book relies on engineering practice and examples rather than reproducing vendor documentation. Consult the current primary source before implementing any integration.

## Primary references

1. [Homey Developer Documentation](https://apps.developer.homey.app/): app capabilities, device cards and platform development guidance.
2. [Homey Support](https://support.homey.app/): current user guidance for flows, devices and troubleshooting.
3. [Mermaid Documentation](https://mermaid.js.org/): diagram syntax used in this book.
4. Manufacturer installation, safety and firmware documentation for every installed device and integration.

## Recommended engineering reading

1. Martin Kleppmann, *Designing Data-Intensive Applications* — useful background on state, failure and consistency.
2. NIST, *Cybersecurity Framework* — a useful way to think about asset awareness and recovery, even in a home setting.
3. The electrical, fire-safety and building regulations applicable where the system is installed.

> [!note]
> References are starting points, not a substitute for current product documentation. Features and integration cards can change with firmware, apps and cloud services.
