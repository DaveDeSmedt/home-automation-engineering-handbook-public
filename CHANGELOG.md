# Changelog

## v1.3.0 — 2026-09-30

### Added

- Lessons from a Live Audit: findings from an AI-assisted review of the running reference home, and how to work with an AI on a live system.
- Reference-home patterns for lighting (context-owned targets, scene vs intensity, override gating, multi-sensor join), CO2-led ventilation, the coverings request queue, house-context variables, and EV-charge battery protection.

### Changed

- Lighting, ventilation and EV-charge protection now described as in daily use in the reference home.
- Repaired wording left behind by earlier generalisation (for example "automation controller" where Homey Pro is meant).


## v1.2.0-rc.1 — Public edition release candidate

### Added

- Pattern framing for state separation, daylight re-evaluation, privacy-aware
  coverings, sensor-health diagnostics, audio reconciliation, and temporary
  EV-charge battery protection.

### Changed

- Generalized installation lessons without publishing names, device labels,
  identifiers, timing routines, or network details.

## v1.1.0-rc1 — Public edition release candidate

### Added

- Book-level front matter: preface, reading guide, publication/privacy policy and bibliography.
- A public-edition audit and review checklist.
- Clear evidence labels for tested behaviour, patterns and proposals.

### Changed

- Reframed the handbook as *Building a Stateful Smart Home: Engineering Reliable Home Automation with Homey Pro*.
- Generalized names, zone topology, device roles and examples.
- Replaced owner-specific metadata with public-edition metadata.
- Reworked navigation, index, standards, release notes and roadmap for readers rather than operators.

### Removed

- Owner identity, identifiable household examples, precise deployment topology and named product-model inventory.
- Instructions that could expose network, security or property details.

### Review status

This is a release candidate. It must be reviewed for residual privacy information, technical accuracy and licensing before publication.

## v1.0.0 — Private handbook baseline

Private operational handbook baseline. Superseded as a public artifact by v1.1.0-rc1; retained only in the private repository history and the untouched `main` branch.
